Colorado Wildfire + Flood Map: mockups

This page shows what the finished Colorado map should look like, so the mapping team is building toward the same thing. It's adapted from Rebuild's NJ Underwater map.

We can get to these screens. Whether the numbers on them are right depends on the data underneath. Every file the map reads has to be clean and checked before it goes on the map, and that's most of the work ahead.

How one tool works

One parcel file, one popup. Every parcel already carries its county, town and both districts, so the switch only changes which boundary the numbers add up to.

House65 districts, with the representative's name.
Senate35 districts, same layout as House.

Unincorporated gets its own area

Each county has a clickable "Unincorporated" area, so properties outside towns have somewhere to show up in the Town view.

Towns across county lines

A town's popup shows the whole town (Erie is in Boulder and Weld). Each county total only counts its own part.

One parcel, one place

Each parcel is assigned by its inside point, so it lands in exactly one town and one district. Nothing is counted twice.

Part 2

How we get there

Each step makes one file. Each file passes its checks before the next step uses it. The map itself never does any math: it only shows numbers that were worked out and checked upstream.

The steps

Left to right. Each step makes one file.

  1. 1 · Raw downloadsParcels, values, census blocks, boundaries. Kept unchanged.Shapefiles & JSONS/
  2. 2 · Parcel BaseOne clean row per property, with its value, census block, town, House and Senate district.co_parcel_base.gpkg
  3. 3a · Flood x parcelShare of each parcel in the FEMA 100-year floodplain.co_flood_x_parcel.csv
  4. 3b · Wildfire x parcelToday's state rating and the 2011 vs 2047 burn chance.co_wildfire_x_parcel.csv
  5. 4 · Public assets x hazardsEach school, fire station, dam and so on, flagged for each hazard.co_public_assets.geojson
  6. 5 · RollupsTotals by county, town, House and Senate district. Same fields in all four.co_*_popup.geojson
  7. 6 · The mapReads only the files from steps 4 and 5, plus parcel tiles for zoomed-in views.index.html

What "clean" means

Every file passes these before the next step uses it. Most data mistakes fail quietly: a broken step produces a normal-looking number, not an error.

CheckWhy it mattersHow to test
One row per propertyThe same property can be listed once per co-owner or split into many shapes, each carrying the full value. Left in, they double count.parcel_key is unique. Duplicates = 0.
Rows add upEvery dropped or merged row should be explained, not lost.Per county: downloaded − placeholders − repeats − merged pieces = final count.
Same parcels in every fileFlood and wildfire results have to line up with the Parcel Base, or totals drift between hazards.Each hazard file has exactly the Parcel Base's parcel_keys. No rows gained or lost in the join.
Gaps stay blank, never 0A 0 reads as "no risk". A county with no data isn't safe, it's unknown.No county on the gap lists shows a 0. Missing values are blank, with a flag column saying why.
Numbers are numbersValues come in as text. A number stored with a comma, like "93,911", can be read as 93.Value columns are numeric. No commas or $ signs. Spot-check a few big ones by hand.
Shares stay between 0 and 1A share above 1 or below 0 means the overlay went wrong.All perc_ columns are 0 to 1, two decimals, no blanks.
Every parcel lands somewhereA parcel with no town or district disappears from those views.Every row has a census block, a town (or Unincorporated), a House district and a Senate district.
Totals reconcileThe same properties are added up four ways. All four have to reach the same state total.Towns + Unincorporated = county. Counties = state. House districts = state. Senate districts = state.
Join on ID and county, never name aloneNames are spelled differently across sources (TWP vs TOWNSHIP). A name-only join quietly drops rows and shows zeros.Join on parcel_key (county code + account). Any name join also uses county.
Spot-check against the sourceCode can be right and the overlay still wrong.10 parcels per county, checked in the FEMA flood map viewer and the state wildfire map.
Ready for the webThe raw parcels have owner names and addresses, which never go public. Big files load slowly.Web files in WGS84 (EPSG:4326), simplified shapes, no owner or address fields.

Part 3

What's in, what's out

The guardrails. If a task doesn't fit "On the map", check before starting it.

On the map

  • Flood today (FEMA 100-year)
  • Wildfire today (state hexagons)
  • Wildfire around 2047 (Forest Service)
  • Flood x wildfire today (both)
  • Properties, value, tax, public assets
  • Estimated residents, clearly labelled as an estimate
  • One tool: county, town (with Unincorporated), House and Senate district

Not on the map

  • Future flood (no open future floodplain for Colorado)
  • "+1 ft" flood heights
  • Drought and extreme heat (not parcel-level data)
  • APTIM's cost of adaptation (separate study)
  • Displacement groups by income (too tricky at parcel level)
  • Town fact sheets
